# Franco Safari

A GitHub Pages-ready static website inspired by the information architecture of a modern Kenya safari/tour operator site.

## Structure
- Hero landing section
- About section
- Safari packages
- Coastal excursions
- Destinations
- Experience/testimonial section
- Contact CTA with Call, WhatsApp and Email buttons
- Responsive mobile navigation

## GitHub Pages
1. Upload the contents of this folder to a GitHub repository.
2. Keep `index.html` in the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`.
5. Save and wait for GitHub Pages to publish.

## Note
The site uses original Franco Safari copy and a comparable high-level structure rather than copying the source site's proprietary text, branding, reviews, or source code.
